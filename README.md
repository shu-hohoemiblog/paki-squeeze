# パキパキスクイーズ（バター）

**遊ぶ:** https://shu-hohoemiblog.github.io/paki-squeeze/

`index.html` をブラウザで開くだけで動く、1ファイル完結のシミュレーター。
外側が半透明のパキパキコーティング、中がぷにぷにの PU でできたバター型スクイーズを再現している。

- 押す・なぞる・長押しで、コーティングがまっすぐなヒビで割れる。割れた破片は表面に浮いて残るか、テーブルに落ちる
- 「引っぱる」モード、または2本指で広げると、バターが伸びる。コーティングは引っぱる向きと直角に割れ、割れ目が開いて中の黄色が見える。離すとぷるんと戻る
- 「指の太さ」スライダーで、割れる範囲・へこみの広さ・音の低さが変わる
- 「にぎる」ボタンを長押しすると、バター全体をぎゅっと握ってパキパキ割る
- 中身はぷにぷにで、押した所がへこんでつぶれ、ゆっくり戻る
- 音はパキパキ系（パキッ・パリパリ・ザクザク）と、中身のねちょだけ（下の「音源」を参照）
- 振動: Android は Vibration API、iPhone（iOS 18 以降の Safari）はシステムのスイッチ触覚を利用
- ボタン類も押すとヒビが入り、破片が飛ぶ
- 「自分の音で試す」から録音や効果音（mp3・m4a・wav）を読み込むと、1回ずつに自動で切り分けて、ねちょ／パキパキの音として使う。読み込んだ音はその端末のブラウザに保存される

## 音源

- パキパキ系の音は Web Audio でその場で合成している
- ねちょ（中身を押す・離す音）は実録音の効果音を使っている。低音（ボヨン成分）をカットし、音量をそろえたうえで MP3 にして `index.html` に埋め込んでいる
